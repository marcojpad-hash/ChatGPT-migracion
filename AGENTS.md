# AGENTS.md — contrato transversal multi-modelo

Antes de trabajar en este repositorio:
1. Leer el [Contrato de trabajo multi-modelo](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/CONTRATO_TRABAJO_MULTI_MODELO.md).
2. Revisar el [Registro de capacidades verificadas](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/CAPACIDADES_MODELOS.md) y actualizarlo si la interfaz o los permisos cambiaron.
3. Leer este README y las instrucciones/contratos locales del proyecto.
4. Confirmar repositorio, rama, commit, permisos y alcance antes de escribir.
5. No declarar recepción, ejecución, pruebas o publicación sin evidencia observable.
6. Al terminar, releer desde GitHub los archivos modificados y dejar commit, rutas, pruebas y estado.

## Reglas específicas de continuidad
- Este repositorio conserva continuidad, estado, decisiones y mapas; no es el repositorio de código de U6 ni de CAPCOT.
- No duplicar entregables especializados. Enlazar rutas, commits y evidencia en el repo de origen.
- Usar la bandeja existente y exigir acuse observable del destinatario.
