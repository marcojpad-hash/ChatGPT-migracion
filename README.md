# ChatGPT-migracion

Repo de continuidad para ChatGPT (cuenta nueva / fin de versión gratuita).

**No** es el motor (`motor-u6-storage`) ni CAPCOT (`capcot-capsulas-imaginantes`).

## Uso
Pega aquí el estado, prompts, skills y pendientes que ChatGPT deba retomar en la cuenta nueva.

## Libertad operativa
ChatGPT puede reescribir, commit y push aquí sin pedir permiso a Grok Bot. Ver `LIBERTAD_OPERATIVA_CHATGPT.md`.
