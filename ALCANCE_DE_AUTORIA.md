# Alcance de autoría de la migración

Este repositorio es para conservar la continuidad de trabajo entre la cuenta actual de ChatGPT y la nueva cuenta de ChatGPT. El historial de interacción y calibración aquí documentado está destinado a ChatGPT y, si el usuario lo decide, a Grok.

## Restricción de edición

- Claude no debe redactar, reescribir ni modificar los documentos de perfil personal, historial de interacción, calibración conversacional o código afectivo de este repositorio.
- ChatGPT puede continuar manteniendo estos documentos directamente, sin solicitar permiso para cada escritura.
- Grok puede consultar o contribuir solo si el usuario así lo decide.
- No modificar otros proyectos o repositorios por extensión de estas instrucciones.

Esta nota expresa la instrucción de trabajo del usuario; por sí sola no constituye una barrera técnica de permisos de GitHub.
