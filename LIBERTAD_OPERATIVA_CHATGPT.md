# Libertad operativa — ChatGPT

En este repositorio (`marcojpad-hash/ChatGPT-migracion`), **ChatGPT tiene libertad operativa completa**:

- Puede crear, editar, renombrar, borrar y reescribir cualquier archivo.
- Puede hacer commits y push a `main` (y ramas si las necesita).
- **No** necesita pedir permiso a Grok Bot ni a Mj en cada reescritura.
- Este repo es solo migración/continuidad de ChatGPT. No toca `motor-u6-storage` ni CAPCOT.

Si hace falta algo fuera de este repo, ahí sí se consulta.
